# 🚀 START HERE

Тебе не нужно знать код. Всю установку делает агент — твоя задача дать ему этот
репозиторий и отвечать «да/нет».

**Что вообще делаем:** ставим claude-recall — память всех твоих сессий Claude Code.
После установки любая сессия умеет: «найди, где я делал X» → нашла → доделала /
дала команду / открыла то самое окно. Подробнее — [README.md](README.md).

## Вариант 1 — копипаст-промпт агенту

Открой Claude Code и вставь целиком:

```text
Прочитай репозиторий https://github.com/rocketmandrey/claude-recall
(README.md и AGENTS.md). Твоя роль — установщик claude-recall.
Веди меня ШАГ ЗА ШАГОМ, объясняй простыми словами, спрашивай подтверждение
перед каждым шагом, который меняет систему.

1. Проверь требования: macOS, python3 >= 3.9, залогиненный claude CLI.
2. Склонируй репо и запусти ./install.sh — покажи, что он сделал
   (CLI, скилл, SessionEnd-хук и permissions в ~/.claude/settings.json).
3. Покажи вывод recall doctor и объясни каждую строку.
4. Спроси меня, запускать ли recall backfill — это LLM-вызов на каждую
   прошлую сессию (~20–40 минут на пару сотен). Если да — запусти и покажи
   recall index.
5. Продемонстрируй на живом примере: recall find по одной из моих недавних
   задач, recall show карточки, и расскажи про три режима
   (finish / handoff / spawn).
```

## Вариант 2 — руками (две команды)

```bash
git clone https://github.com/rocketmandrey/claude-recall && cd claude-recall
./install.sh
```

## ✅ Что агент сделает за тебя

- Поставит CLI `recall`, скилл-оркестратор и SessionEnd-хук.
- Аккуратно смержит `~/.claude/settings.json`: твои хуки и настройки не тронет,
  добавит только своё (включая permissions `Bash(recall *)` — чтобы recall работал
  в новых сессиях без промптов).
- С твоего «да» проиндексирует прошлые сессии и покажет, как искать.

## 🙅 Чего агент НЕ сделает

- Не отправит твои данные никуда: карточки и индекс лежат локально и не покидают машину.
- Не запустит backfill (массовые LLM-вызовы) без твоего явного «да».
- Не удалит ни одной сессии из индекса без подтверждения.
- Не попросит ни одного API-ключа — их тут просто нет.
