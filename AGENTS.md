# AGENTS.md — правила для агента

Ты — Claude Code / Codex, тебе дали этот репозиторий. Читай этот файл первым.
У тебя один из двух сценариев: **установка** (человек хочет поставить recall себе)
или **оркестрация** (recall уже стоит, человек ищет/возобновляет сессии).

## Порядок чтения

1. `AGENTS.md` — этот файл.
2. `README.md` — что это и как устроено (раздел «⚠️ Прочитай ПЕРВЫМ» — обязательно).
3. `skill/SKILL.md` — рабочий цикл оркестратора: find → show → три режима.
4. `bin/recall` — только если нужно лезть внутрь; весь продукт в одном файле.

## Жёсткие правила (нарушение = стоп и спросить человека)

1. **Данные не публикуются.** `~/.claude/session-recaps/` — выжимка личных сессий
   (имена, ссылки). Не коммитить, не пушить, не вставлять карточки в публичные места.
2. **`recall remove` — только с подтверждением.** Покажи строку индекса, дождись «да».
   Удаление ставит tombstone — вернуть можно только `recall recap <transcript> --force`.
3. **`recall backfill` — только с явного «да».** Это LLM-вызов на каждую прошлую
   сессию; предупреди про время (~20–40 мин) и предложи ограничить `--days`.
4. **`~/.claude/settings.json` только мержить, не перезаписывать.** install.sh уже
   делает это правильно (хук + permissions); руками не редактируй без нужды.
5. **Секретов в репо нет и не появится.** Никаких ключей, токенов, реальных ФИО
   и телефонов — ни в коде, ни в примерах, ни в коммитах.

## Рабочий цикл оркестратора

- Ищи по ОСНОВЕ слова: «Ивановой» → `иванов`, «выгрузку» → `выгрузк`.
- `recall find <основы...>` → один уверенный кандидат — работай; 2+ правдоподобных —
  построй селектор (папка + дата + контекст на каждого, последний вариант —
  «копнуть глубже»), не выбирай сам.
- `recall show <id8>` → карточки часто достаточно (артефакты, метод, next).
  Нужна глубина — сырой transcript из `~/.claude/projects/`.
- Режим по формулировке: задача → **finish** (повтори метод здесь);
  «дай команду» → **handoff** (`recall cmd`); «открой/переключи» → **spawn**
  (`recall open`).

## Что нужно от человека

macOS, python3 ≥ 3.9, залогиненный claude CLI. Всё. Ключей — нет.
